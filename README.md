# Analog-IC-Design-Layout-Using-45nm-Technology
This project involves schematic design and physical layout of CMOS circuits using 45nm technology in Cadence Virtuoso. I designed inverter, AND, OR, NAND, NOR, AOI gates, comparator, and logic circuits from expressions using stick diagrams. All layouts were verified using DRC and LVS, and waveforms were checked for correct operation.
